<SlideMotionDemo />

```tsx
import { Slide } from '@package/motion';

<Slide visible={visible} from="bottom" distance={16} sizing="intrinsic">
  <Content />
</Slide>;
```

`MotionBox`를 따로 감쌀 필요 없이 바로 사용할 수 있습니다.

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `visible` | `boolean` | — | 표시 여부 |
| `from` | `'top' \| 'bottom' \| 'left' \| 'right'` | — | 시작 방향 |
| `distance` | `number` | `16` | 이동 거리 |
| `duration` | `number` | `200` | 재생 시간(ms) |
| `fade` | `boolean` | `true` | 투명도 효과를 함께 적용할지 여부 |
| `sizing` | `'inherit' \| 'intrinsic' \| 'fill'` | `'inherit'` | 영역의 크기 설정 |
| `appear` | `boolean` | `true` | 처음 나타날 때 애니메이션 적용 여부 |
| `unmountOnExit` | `boolean` | `true` | 사라진 뒤 요소를 제거할지 여부 |

스위치처럼 요소를 계속 유지하면서 위치만 바꾸려면 `fade={false}`,
`appear={false}`, `unmountOnExit={false}`를 사용하세요.
