title: Badge
description: 텍스트나 점으로 상태를 간결하게 표시합니다
---

## 예제

<BadgeDemo />

```tsx
import { Badge } from '@package/design-system';

<Badge label="PRO" variant="primary" />
<Badge dot variant="error" />
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `label` | `string` | — | 배지 텍스트 |
| `variant` | `'primary' \| 'success' \| 'error' \| 'neutral'` | `'primary'` | 상태에 맞는 색상 |
| `dot` | `boolean` | `false` | 텍스트 대신 점으로 표시할지 여부 |
