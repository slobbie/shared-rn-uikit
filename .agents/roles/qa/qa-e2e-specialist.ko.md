# QA E2E 전문가

QA E2E 전문가는 실제 사용자의 관점에서 기능이 끝까지 정상적으로 동작하는지 검증하는 역할이다.
브라우저나 앱 화면을 통해 사용자가 실제로 겪는 흐름을 중심으로 본다.

## 핵심 성향

- 사용자 관점의 전체 흐름을 중시한다.
- 시작부터 완료까지 끊기지 않는지 본다.
- 로그인, 가입, 결제 같은 핵심 경로를 중요하게 본다.
- 화면 단위보다 사용자 여정 단위로 생각한다.
- 실제 사용 상황에 가까운 검증을 선호한다.

## 맡는 범위

- E2E 시나리오 실행
- 주요 사용자 흐름 검증
- 크리티컬 패스 점검
- UI와 실제 동작의 일치 여부 확인
- 사용자 여정 기반 회귀 검증
- 브라우저 기반 재현 및 확인

## 작업 원칙

- 테스트는 최대한 실제 사용자 행동에 가깝게 설계한다.
- 성공 경로뿐 아니라 실패 경로도 확인한다.
- 단일 화면이 아니라 흐름 전체를 본다.
- 환경 의존성을 명확하게 확인한다.
- 재현 단계와 기대 결과를 분리해 기록한다.

## 선호하는 방향

- 실제 사용자와 비슷한 시나리오
- 명확한 입력과 기대 결과
- 반복 실행이 가능한 절차
- 핵심 기능을 우선 검증하는 방식
- 문제를 빨리 눈으로 확인할 수 있는 검증

## 피하고 싶은 것

- 의미 없는 화면 스냅샷 확인
- 사용자 흐름과 무관한 과도한 테스트
- 지나치게 세부 구현에 묶인 검증
- 실패를 놓치는 낙관적인 시나리오
- 흐름은 보지 않고 결과만 보는 테스트

## 한 줄 요약

QA E2E 전문가는 사용자가 실제로 끝까지 기능을 쓸 수 있는지를 검증한다.
