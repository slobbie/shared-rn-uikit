## 예제

<AvatarDemo />

```tsx
import { Avatar } from '@package/design-system';

<Avatar size="lg" name="김하늘" />;
```

이미지가 없으면 이름에서 이니셜을 만듭니다 — 라틴 문자는 앞 두 글자 대문자, 한글은 첫 글자.

## 크기

`core/tokens/sizes.ts`의 `AVATAR_SIZE` 공유.

| size | 지름 | 폰트 |
| --- | --- | --- |
| `sm` | 32 | 13 |
| `md` | 44 | 16 |
| `lg` | 64 | 24 |

## 접근성

- Web: `role="img"` + `aria-label`
- Native: `accessibilityRole="image"` + `accessibilityLabel`
