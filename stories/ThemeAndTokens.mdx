# Theme and Tokens

## 어디를 보면 되나
토큰과 시맨틱 테마는 아래 순서로 확인하면 됩니다.

1. `Foundations/Theme Tokens`
2. 해당 토큰을 실제로 쓰는 component story
3. 필요 시 `shared/utils/lib/` 구현

## 현재 노출된 범위
`Foundations/Theme Tokens`에서 확인 가능:
- base `variant`
- base `colors`
- `background`
- semantic theme mapping
- typography scale
- spacing scale

## 확인 포인트
- token 변경이 semantic layer에 어떻게 매핑되는지
- typography variant가 실제로 어느 크기/행간인지
- spacing scale이 component spacing 감각과 맞는지
- button / text / border / background가 일관된 naming을 가지는지

## 주의
- Storybook은 token source를 **설명하고 시각화**하는 용도입니다.
- 실제 source of truth는 `shared/utils/lib/themeToken*`, `createTheme`, `createSemanticTheme` 입니다.
- preview용 문서에 맞춘 별도 token 체계를 만들지 않습니다.
