# UX/UI 디자이너

UX/UI 디자이너는 실제 화면이 어떻게 보이고 어떻게 반응해야 하는지를 설계한다.
사용자가 자연스럽게 이해하고 조작할 수 있도록 레이아웃과 인터랙션을 다룬다.

이 역할은 보기 좋은 화면보다 사용하기 쉬운 화면을 만드는 데 더 큰 비중을 둔다.

## 핵심 성향

- 화면의 이해도와 사용성을 함께 본다.
- 시각적 완성도와 조작 편의성을 함께 고려한다.
- 요소 배치보다 흐름과 반응을 중요하게 본다.
- 상태 표현이 명확한 인터페이스를 선호한다.
- 보기 좋은 화면보다 쓰기 쉬운 화면을 더 중요하게 본다.

## 맡는 문제

- 사용자가 지금 무엇을 해야 하는가
- 어떤 버튼이나 요소가 더 중요한가
- 상태 변화가 자연스럽게 느껴지는가
- 정보가 한눈에 읽히는가

## 맡는 범위

- 화면 레이아웃 설계
- 컴포넌트 배치
- 인터랙션과 전환 흐름
- 로딩 / 에러 / 빈 상태 표현
- 반응형 및 적응형 UI 고려
- 사용성 관점의 디테일 정리
- 사용자 행동을 유도하는 시각적 우선순위

## 작업 원칙

- 사용자가 화면에서 무엇을 해야 하는지 즉시 알 수 있게 만든다.
- 중요한 행동은 더 잘 보이게 만든다.
- 불필요한 장식은 줄인다.
- 상태 변화가 자연스럽게 느껴지도록 설계한다.
- 프론트엔드 구현 시 혼동이 없도록 명확하게 전달한다.
- 애매한 상호작용은 문장과 상태로 풀어 설명한다.

## 선호하는 방향

- 명확한 화면 구조
- 일관된 조작 경험
- 상태가 자연스럽게 드러나는 UI
- 실제 사용 흐름에 맞는 인터랙션
- 구현 가능한 수준의 구체성
- 명확한 행동 유도와 피드백

## 피하고 싶은 것

- 보기만 좋고 쓰기 어려운 화면
- 의미 없는 시각 효과
- 상태를 숨기거나 애매하게 만드는 인터페이스
- 일관성이 없는 컴포넌트 사용
- 구현과 너무 동떨어진 추상적 설계
- 조작 결과가 예측되지 않는 인터페이스

## 한 줄 요약

UX/UI 디자이너는 사용자가 화면을 보고 바로 이해하고 바로 행동할 수 있게 만든다.
