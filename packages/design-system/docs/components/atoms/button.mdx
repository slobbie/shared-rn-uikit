## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | `'primary' \| 'secondary' \| 'ghost'` | `'primary'` | 버튼 스타일 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 크기 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `loading` | `boolean` | `false` | 로딩 표시와 함께 입력을 막을지 여부 |
| `onPress` | `() => void` | — | 버튼을 눌렀을 때 실행할 함수 |
| `accessibilityLabel` | `string` | — | 버튼에 텍스트가 없을 때 읽어 줄 설명 |

## 접근성

- Web: `<button>` 요소, `disabled`/`aria-busy` 반영
- Native: `accessibilityRole="button"`, `accessibilityState={{ disabled, busy }}`
