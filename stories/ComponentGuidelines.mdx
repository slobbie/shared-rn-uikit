# Component Guidelines

## story 작성 기준
- `Meta`, `args`, `argTypes`를 기본 구조로 사용합니다.
- baseline reference story와 비교/상태 story를 분리합니다.
- control은 실제로 탐색 가치가 있는 prop만 노출합니다.
- component API를 Storybook 편의에 맞춰 바꾸지 않습니다.

## coverage 기준

### atom
- 핵심 variant
- disabled / selected / error 등 대표 상태
- 의미 있는 control

### molecule / layout
- 실사용 composition
- 긴 텍스트 / 밀집 레이아웃 / 빈 상태 같은 edge case
- child 관계가 보이는 예제

## preview 규칙
- 전역 provider는 `.storybook/preview.ts` 기준으로 유지합니다.
- width / surface / overlay 같은 shell은 공용 preview helper를 우선 사용합니다.
- browser-only helper는 shared public API 밖에 둡니다.

## 문서와 코드의 경계
- story는 사용 예시와 검토 surface입니다.
- shared implementation 규칙은 `shared/ui/`, `shared/utils/lib/`가 기준입니다.
- docs는 contributor가 빨리 이해하도록 돕는 요약층입니다.
