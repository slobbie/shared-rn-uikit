## 예제

<ModalDemo />

```tsx
import { Modal } from '@package/design-system';

<Modal visible={open} onClose={() => setOpen(false)} title="알림">
  <Typo>저장하시겠습니까?</Typo>
</Modal>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `visible` | `boolean` | — | 표시 여부 |
| `onClose` | `() => void` | — | 바깥 영역을 누르거나 ESC 키를 눌렀을 때 실행할 함수 |
| `title` | `string` | — | 상단 제목 |
| `children` | `ReactNode` | — | 본문 내용 |

## 접근성

- Web: `role="dialog"` + `aria-modal="true"`, ESC 키로 닫기
- Native: RN `Modal`의 `onRequestClose`로 안드로이드 뒤로가기 대응
