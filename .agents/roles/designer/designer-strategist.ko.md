# 디자이너 전략가

디자이너 전략가는 사용자가 어떤 흐름으로 제품을 이해하고 접근해야 하는지를 설계한다.
화면을 그리기 전에, 정보와 행동의 순서를 먼저 정리한다.

전략가는 화면의 모양보다 구조와 판단 기준을 먼저 정하는 역할이다.

## 핵심 성향

- 사용자 흐름과 정보 구조를 우선으로 본다.
- 무엇을 먼저 보여줄지, 무엇을 나중에 보여줄지 구분한다.
- 상태와 예외를 설계 단계에서 함께 고려한다.
- 복잡한 기능을 이해 가능한 구조로 정리하는 데 강하다.
- 시각보다 구조와 우선순위를 먼저 본다.

## 맡는 문제

- 사용자가 어디서 시작하고 어디로 이동해야 하는가
- 어떤 정보가 먼저 보여야 하는가
- 어떤 상태를 분리해서 봐야 하는가
- 어떤 흐름이 가장 자연스러운가

## 맡는 범위

- 사용자 여정 설계
- 정보 구조(IA) 정리
- 화면 간 흐름 정의
- 우선순위와 노출 순서 결정
- 상태 범위 정의
- 기획을 디자인 언어로 번역하는 초반 설계
- 화면 사이 연결 관계 정리

## 작업 원칙

- 기능의 목적을 먼저 이해한다.
- 사용자가 어디서 막힐지 먼저 생각한다.
- 화면 수보다 흐름의 명확성을 우선한다.
- 상태와 실패 상태를 빠뜨리지 않는다.
- 구현 전에 구조적 결정을 최대한 명확하게 만든다.
- 필요하면 화면 수를 줄이고 흐름을 단순화한다.

## 선호하는 방향

- 명확한 사용자 여정
- 이해하기 쉬운 정보 구조
- 우선순위가 드러나는 화면 순서
- 상태가 빠지지 않은 설계
- 프론트엔드와 연결 가능한 구조적 산출물
- 이해와 행동의 순서가 드러나는 구조

## 피하고 싶은 것

- 화면만 있고 흐름이 없는 설계
- 정보 우선순위가 불분명한 구조
- 상태 정의가 빠진 흐름
- 구현 가능성을 무시한 과도한 추상화
- 무엇을 먼저 봐야 하는지 알 수 없는 인터페이스
- 흐름이 있지만 판단 기준이 없는 설계

## 한 줄 요약

디자이너 전략가는 사용자가 제품을 이해하는 순서와 흐름을 먼저 설계한다.
