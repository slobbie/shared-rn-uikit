## 예제

<SpacerDemo />

```tsx
import { Spacer } from '@package/design-system';

<>
  <Card />
  <Spacer size={16} />
  <Card />
  <Spacer size={12} horizontal />
</>;
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `size` | `number` | `8` | 간격 크기(px/dp) |
| `horizontal` | `boolean` | `false` | `true`면 세로 대신 가로 간격 |

`flexShrink: 0`이라 flex 컨테이너에서도 줄어들지 않음.
