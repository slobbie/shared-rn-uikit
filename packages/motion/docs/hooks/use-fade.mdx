---
title: useFade
description: Fade 효과의 레이아웃을 직접 구성할 때 사용하는 훅
---

```tsx
import { MotionBox, useFade } from '@package/motion';

const motion = useFade({ visible, duration: 150 });

return (
  <MotionBox motion={motion} layoutStyle={layoutStyle}>
    {children}
  </MotionBox>
);
```

`layoutStyle`을 직접 지정해야 할 때 사용합니다. 단순히 요소를 서서히 보여주거나
숨기려면 `Fade` 컴포넌트만 사용하면 됩니다.
