# shared-rn-uikit

`shared-rn-uikit`은 React Native 중심으로 시작한 shared UI kit이며,
현재 Storybook을 통해 **문서화 + 탐색 + 공용화 검증 기반**을 단계적으로 정비하고 있습니다.

## 지금 Storybook에서 볼 수 있는 것
- `Atoms`, `Molecules`, `Layout`, `Utils` 단위 컴포넌트 스토리
- 공통 preview wrapper가 적용된 대표 composition story
- `Foundations/Theme Tokens`에서 확인할 수 있는 theme/token 가시화 페이지

## 현재 문서 구조
- `Docs/Introduction`: Storybook의 목적과 현재 범위
- `Docs/Getting Started`: 어디부터 보면 되는지
- `Docs/Theme and Tokens`: theme/token 레이어 보는 법
- `Docs/Component Guidelines`: story/component 작성 기준 요약
- `Docs/Contribution Guide`: 변경 시 기본 체크리스트
- `Docs/Playground Guide`: playground 단계의 방향

## 이 Storybook의 목적
1. 컴포넌트 public surface를 빠르게 확인한다.
2. 상태/variant coverage를 눈으로 검토한다.
3. token/theme 변경 영향을 먼저 확인한다.
4. 장기적으로 React / React Native 공용 검증 기반으로 키운다.

## 권장 탐색 순서
1. `Docs/Getting Started`
2. `Foundations/Theme Tokens`
3. 필요한 component story
4. `Docs/Component Guidelines`
