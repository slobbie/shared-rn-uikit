## 예제

<CheckboxDemo />

```tsx
import { Checkbox } from '@package/design-system';

<Checkbox
  checked={agreed}
  onChange={setAgreed}
  label="이용약관 동의"
  accessibilityLabel="이용약관 동의"
/>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | 체크 상태 |
| `onChange` | `(next: boolean) => void` | — | 선택 상태가 바뀔 때 실행할 함수 |
| `label` | `string` | — | 컨트롤 오른쪽 레이블 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `accessibilityLabel` | `string` | — | 스크린리더 레이블 |

## 접근성

- Web: `role="checkbox"` + `aria-checked`
- Native: `accessibilityRole="checkbox"` + `accessibilityState={{ checked, disabled }}`
