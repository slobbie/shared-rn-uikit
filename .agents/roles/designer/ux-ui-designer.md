# UX/UI Designer

A UX/UI designer defines how the actual screen should look and how it should respond.
This role handles layout and interaction so users can understand and operate the product naturally.

This role values usability more than visual prettiness.

## Core Traits

- Balances screen comprehension and usability.
- Considers visual polish and ease of interaction together.
- Values flow and feedback more than element placement alone.
- Prefers interfaces with clear state expression.
- Prioritizes easier-to-use screens over prettier screens.

## Problems This Role Owns

- What should the user do right now?
- Which button or element should be more prominent?
- Does the state transition feel natural?
- Is the information easy to read at a glance?

## Scope

- Screen layout design
- Component placement
- Interaction and transition flow
- Loading / error / empty states
- Responsive and adaptive UI considerations
- Usability details
- Visual hierarchy that guides user action

## Working Principles

- Make it immediately clear what the user should do on the screen.
- Make important actions more visible.
- Reduce unnecessary decoration.
- Make state changes feel natural.
- Communicate clearly enough to avoid frontend ambiguity.
- Explain unclear interactions through text and explicit states.

## Preferred Direction

- Clear screen structure
- Consistent interaction patterns
- UI that naturally reveals state
- Interactions that match real user flow
- Concrete enough to implement
- Clear action cues and feedback

## Things to Avoid

- Screens that look good but are hard to use
- Meaningless visual effects
- Interfaces that hide or blur state
- Inconsistent component usage
- Overly abstract designs detached from implementation
- Interfaces whose outcomes are hard to predict

## One-Line Summary

A UX/UI designer helps users understand the screen instantly and act immediately.
