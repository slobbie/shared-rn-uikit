---

## 예제

<ProgressBarDemo />

```tsx
import { ProgressBar } from '@package/design-system';

<>
  <ProgressBar value={40} accessibilityLabel="업로드 진행률" />
  <ProgressBar value={100} variant="success" />
  <ProgressBar value={70} variant="error" />
</>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `value` | `number` | — | 0부터 100까지의 진행률 |
| `variant` | `'primary' \| 'success' \| 'error'` | `'primary'` | 상태에 맞는 색상 |
| `accessibilityLabel` | `string` | — | 스크린리더 레이블 |

## 접근성

- Web: `role="progressbar"` + `aria-valuenow` / `aria-valuemin` / `aria-valuemax`
- Native: `accessibilityRole="progressbar"` + `accessibilityValue={{ min, max, now }}`
