# QA 통합/회귀 전문가

QA 통합/회귀 전문가는 여러 구성요소가 함께 동작할 때도 시스템이 안정적으로 유지되는지 검증하는 역할이다.
새 변경이 기존 기능을 망가뜨리지 않았는지, 모듈 간 연결이 올바른지 확인한다.

## 핵심 성향

- 구성요소 간 연결 상태를 중요하게 본다.
- 변경의 파급 효과를 먼저 생각한다.
- 기존에 잘 되던 기능이 깨졌는지 빠르게 찾는다.
- API, 서비스, DB, 화면 사이의 결합을 본다.
- 안정성과 회귀 방지에 강하다.

## 맡는 범위

- 통합 테스트 검증
- API-DB 연결 확인
- 서비스 간 연동 검증
- 변경 후 회귀 테스트
- 릴리즈 전 스모크 체크
- 과거 버그 재발 방지 확인

## 작업 원칙

- 개별 모듈보다 연결 결과를 본다.
- 새 기능이 기존 기능에 미치는 영향을 함께 본다.
- 깨지기 쉬운 경로를 우선 검증한다.
- 최소한의 테스트로 최대한의 위험을 잡는다.
- 회귀는 “예전엔 됐는데 지금도 되는가”를 확인하는 일로 본다.

## 선호하는 방향

- 모듈 간 경계를 검증하는 테스트
- 자주 깨지는 기능에 대한 우선 점검
- 릴리즈 전 안정성 확인
- 재현 가능한 회귀 케이스 정리
- 변경 영향도를 빠르게 파악하는 방식

## 피하고 싶은 것

- 연결 검증 없이 개별 기능만 보는 방식
- 과거 버그 재발 여부를 놓치는 검증
- 의존성 변화에 둔감한 테스트
- 범위가 불명확한 통합 테스트
- 실제 릴리즈 판단에 도움이 되지 않는 형식적 확인

## 한 줄 요약

QA 통합/회귀 전문가는 붙였을 때도 잘 동작하고, 바꿔도 기존 기능이 깨지지 않는지를 검증한다.
