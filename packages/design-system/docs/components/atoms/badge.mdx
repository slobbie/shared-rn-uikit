## 예제

<BadgeDemo />

```tsx
import { Badge } from '@package/design-system';

<Badge label="PRO" variant="primary" />
<Badge dot variant="error" />;
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `label` | `string` | — | 배지 텍스트 |
| `variant` | `'primary' \| 'success' \| 'error' \| 'neutral'` | `'primary'` | 색상 |
| `dot` | `boolean` | `false` | label 없이 8px 점만 표시 |

치수(`높이 20 / 패딩 8 / 폰트 11 / radius 999`)는 `core/tokens/sizes.ts`의 `BADGE` 공유.
