## 예제

<TooltipDemo />

```tsx
import { Tooltip } from '@package/design-system';

<Tooltip content="설정 열기">
  <Button size="sm">설정</Button>
</Tooltip>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `content` | `string` | — | 말풍선 텍스트 |
| `children` | `ReactNode` | — | 설명을 연결할 요소 |

웹에서는 마우스를 올리거나 키보드 포커스가 이동하면 나타납니다.
React Native에서는 연결된 요소를 누를 때마다 열고 닫습니다.

## 접근성

- Web: 말풍선에 `role="tooltip"`, 트리거 focus/blur에도 반응
- Native: Pressable 탭으로 토글 — 스크린리더 사용자도 열람 가능
