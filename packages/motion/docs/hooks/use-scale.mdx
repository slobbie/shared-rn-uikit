---
title: useScale
description: Scale의 플랫폼 바인딩과 presence 상태를 만드는 저수준 훅
---

```tsx
import { MotionBox, useScale } from '@package/motion';

const motion = useScale({ visible, from: 0.92 });

return <MotionBox motion={motion}>{children}</MotionBox>;
```

반환된 바인딩은 Web에서는 Motion target, Native에서는 Reanimated animated style을 포함한다. 소비자는 내부 값을 해석하지 않고 `MotionBox`에 전달한다.
