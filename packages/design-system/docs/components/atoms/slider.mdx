## 예제

<SliderDemo />

```tsx
import { Slider } from '@package/design-system';

<Slider
  value={volume}
  onChange={setVolume}
  min={0}
  max={100}
  step={1}
  accessibilityLabel="볼륨"
/>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `value` | `number` | — | 현재 값 |
| `onChange` | `(next: number) => void` | — | 값이 바뀔 때 실행할 함수 |
| `min` | `number` | `0` | 최솟값 |
| `max` | `number` | `100` | 최댓값 |
| `step` | `number` | `1` | 한 번에 변경할 값의 간격 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `accessibilityLabel` | `string` | — | 스크린리더 레이블 |

## 접근성

- Web: 네이티브 `<input type="range">` — 키보드 화살표 조작 기본 지원
- Native: `accessibilityRole="adjustable"` + `accessibilityValue={{ min, max, now }}`
