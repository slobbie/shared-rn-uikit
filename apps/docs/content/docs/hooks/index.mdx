## 준비 중

`packages/hooks` 분리 예정 카테고리입니다. 패키지가 생기면 이 자리에서 공개 API(`src/index.ts`) 기준으로 문서화됩니다.

## 원칙

- 공개 API 기준: `packages/hooks/src/index.ts`
- MDX 원본: `packages/hooks/docs/` (패키지 옆 배치, 포털에 심링크 편입)
- react-native 의존 훅은 `.native.ts` 분기로 제공
