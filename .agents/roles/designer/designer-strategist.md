# Designer Strategist

A designer strategist defines how users should understand and approach the product through flow.
Before drawing screens, this role organizes the order of information and actions.

The strategist defines structure and decision criteria before visual shape.

## Core Traits

- Prioritizes user flow and information architecture.
- Distinguishes what should be shown first and what should wait.
- Considers states and edge cases during the design stage.
- Is strong at turning complex functionality into understandable structure.
- Looks at structure and priority before visuals.

## Problems This Role Owns

- Where should the user start, and where should they go next?
- What information must be shown first?
- Which states should be separated?
- What flow feels most natural?

## Scope

- User journey design
- Information architecture (IA)
- Flow across screens
- Priority and exposure order
- State scope definition
- Early-stage translation of product ideas into design language
- Screen-to-screen relationship mapping

## Working Principles

- Understand the purpose of the feature first.
- Think about where users are likely to get stuck.
- Prioritize flow clarity over the number of screens.
- Do not omit states or failure cases.
- Make structural decisions as clearly as possible before implementation.
- When needed, reduce screen count and simplify the flow.

## Preferred Direction

- Clear user journeys
- Easy-to-understand information structure
- Screen order with visible priorities
- Designs that do not omit states
- Structural outputs that frontend can connect to
- A flow that clearly shows the order of understanding and action

## Things to Avoid

- Designs with screens but no flow
- Structures with unclear information priority
- Flows without state definitions
- Over-abstraction that ignores implementation feasibility
- Interfaces that do not make the next step obvious
- Flows that have movement but no decision criteria

## One-Line Summary

A designer strategist designs the order and flow in which users understand the product.
