## 예제

클릭해서 선택을 토글해 보세요.

<ChipDemo />

```tsx
import { Chip } from '@package/design-system';

<Chip
  label="React"
  selected={selected.includes('React')}
  onPress={() => toggle('React')}
/>
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `label` | `string` | — | 칩 텍스트 |
| `selected` | `boolean` | `false` | 선택 여부 |
| `onPress` | `() => void` | — | 칩을 눌렀을 때 실행할 함수 |
| `disabled` | `boolean` | `false` | 비활성화 |

## 접근성

- Web: `<button aria-pressed>`
- Native: `accessibilityState={{ selected }}`
