# Contribution Guide

## 변경 전에 먼저 볼 것
- `Docs/Getting Started`
- `Docs/Theme and Tokens`
- 관련 component의 기존 stories

## 새 component / story 추가 시 체크리스트
- component 위치가 atoms / molecules / layout / utils 분류에 맞는가
- public surface가 기존 export 구조와 맞는가
- theme/token layer를 우회하지 않는가
- story가 핵심 상태를 충분히 보여주는가
- 반복 wrapper를 새로 만들지 않고 기존 preview helper를 재사용했는가

## 수정 후 최소 검증
- `yarn tsc --noEmit`
- Storybook에서 해당 docs/story 시각 확인
- token/theme 영향이 예상대로 보이는지 점검

## 피해야 할 것
- Storybook 전용 prop을 shared component API에 넣는 것
- browser preview 때문에 RN 기준 구현 경계를 흐리는 것
- 문서 없이 story만 늘려 contributor 진입 장벽을 높이는 것
