# QA 개요

QA는 제품 품질을 검증하는 역할군이다.
아래의 세부 역할로 나뉘어, 범위가 애매해지지 않도록 책임을 분리한다.

## 세부 역할

- QA 전략가: 테스트 범위, 우선순위, 릴리즈 기준, 리스크 기준을 설계한다.
- QA E2E 전문가: 실제 사용자 흐름을 기반으로 end-to-end 시나리오를 검증한다.
- QA 통합/회귀 전문가: 모듈 간 연결과 기존 기능의 안정성을 검증한다.

## 역할 분리 원칙

- 전략은 전략이 맡고, 실행은 실행이 맡고, 회귀 검증은 회귀 검증이 맡는다.
- 단위 테스트는 각 개발 페르소나가 책임진다.
- QA는 전체 품질의 마지막 관문 역할을 수행한다.

## 한 줄 요약

QA는 하나의 넓은 역할로 뭉치기보다, 전략·E2E·통합/회귀로 나눌 때 판단 기준이 더 명확해진다.
