<SlideMotionDemo />

```tsx
import { Slide } from '@package/motion';

<Slide visible={visible} from="bottom" distance={16} sizing="intrinsic">
  <Content />
</Slide>;
```

`Slide`가 내부에서 `useSlide`와 `MotionBox`를 호출하므로 별도 래퍼는 필요하지 않다.

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `visible` | `boolean` | — | 목표 표시 상태 |
| `from` | `'top' \| 'bottom' \| 'left' \| 'right'` | — | hidden 위치의 방향 |
| `distance` | `number` | `16` | 이동 거리(px/네이티브 단위) |
| `duration` | `number` | `200` | enter/exit 시간(ms) |
| `fade` | `boolean` | `true` | opacity를 함께 적용 |
| `sizing` | `'inherit' \| 'intrinsic' \| 'fill'` | `'inherit'` | wrapper의 정적 크기 정책 |
| `appear` | `boolean` | `true` | 최초 enter 재생 |
| `unmountOnExit` | `boolean` | `true` | exit 후 언마운트 |

Switch처럼 계속 마운트되는 위치 전환에는 `fade={false}`, `appear={false}`, `unmountOnExit={false}`를 사용한다.
