## ThemeProvider

앱의 최상단을 `ThemeProvider`로 감싸면 모든 컴포넌트에 같은 테마가 적용됩니다.
별도로 설정하지 않으면 기본 테마를 사용합니다.

```tsx
import { ThemeProvider } from '@package/design-system';

const App = () => (
  <ThemeProvider>
    <YourApp />
  </ThemeProvider>
);
```

## createTheme

`createTheme`에 바꾸고 싶은 값만 전달하면 나머지는 기본 테마를 유지합니다.

```tsx
import { createTheme, ThemeProvider } from '@package/design-system';

const theme = createTheme({
  colors: {
    primary: '#0f766e',
  },
});
```

## useTheme

컴포넌트 안에서 현재 적용된 테마를 가져올 때 사용합니다.

```tsx
import { useTheme } from '@package/design-system';

const Example = () => {
  const { theme } = useTheme();
  return <span style={{ color: theme.colors.button.primary }}>primary</span>;
};
```

## 주요 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `colors.button.primary` | `#2089dc` | 주요 액션 |
| `colors.button.secondary` | `#ca71eb` | 보조 액션 |
| `colors.text.black` | `#242424` | 기본 텍스트 |
| `colors.text.grey2` | `#5e6977` | 보조 텍스트 |
