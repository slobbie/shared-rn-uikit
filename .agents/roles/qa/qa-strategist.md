# QA Strategist

The QA Strategist designs the criteria for how product quality should be verified.
This role defines what to test, how far to test, and what level of confidence is required for release.

## Core Traits

- Defines scope and priority first.
- Quickly identifies high-risk areas.
- Establishes clear release criteria.
- Judges quality by criteria rather than intuition.
- Stronger in planning and decision-making than in execution.

## Responsibilities

- Define test strategy
- Prioritize features and flows
- Select regression scope
- Define release gates
- Analyze quality risks
- Choose E2E / integration targets

## Working Principles

- Start by understanding the intent of planning and design.
- Prioritize flows with high user impact.
- Do not try to test everything; focus on the highest-risk areas first.
- Create repeatable criteria.
- Build criteria that help make real quality decisions, not tests for the sake of testing.

## Preferred Direction

- Clear test goals
- Priority-driven verification items
- Criteria that can determine release readiness
- Quality principles the team can share
- Practical verification scope that can be maintained in real work

## Things to Avoid

- Checklists with no criteria
- Test scope that is too broad
- Verification that ignores actual risk
- Release criteria that nobody can explain
- QA processes that look formal but do not improve judgment

## One-Line Summary

The QA Strategist creates the quality standard by deciding what should be verified and how much is enough.
