## 예제

<SegmentedControlDemo />

```tsx
import { SegmentedControl } from '@package/design-system';

<SegmentedControl
  options={['전체', '진행중', '완료']}
  value={filter}
  onChange={setFilter}
/>;
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `options` | `string[]` | — | 세그먼트 라벨 목록 |
| `value` | `string` | — | 선택된 라벨 |
| `onChange` | `(next: string) => void` | — | 선택 변경 핸들러 |
| `disabled` | `boolean` | `false` | 비활성화 |

높이 36 / 패딩 2 치수는 `core/tokens/display.ts`의 `SEGMENTED` 공유.
컨테이너 `grey5` 배경, 선택 항목은 흰 배경 + 그림자.

## 접근성

- Web: 컨테이너 `role="tablist"`, 항목 `role="tab"` + `aria-selected`
- Native: RN에 `tab` 롤이 없어 `accessibilityRole="button"` + `accessibilityState={{ selected }}`
