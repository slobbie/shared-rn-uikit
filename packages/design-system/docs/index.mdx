---

`@package/design-system`은 웹과 React Native에서 같은 방식으로 사용할 수 있는
컴포넌트 라이브러리입니다.

플랫폼에 따라 import 경로나 사용법을 바꿀 필요가 없습니다.

```tsx
import { Button, Switch, Typo } from '@package/design-system';

<Button onPress={handleSave}>저장</Button>
<Switch value={enabled} onChange={setEnabled} />
<Typo variant="body">알림을 받을 수 있습니다.</Typo>
```
