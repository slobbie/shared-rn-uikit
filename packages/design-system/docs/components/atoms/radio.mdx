## 예제

<RadioDemo />

```tsx
import { Radio } from '@package/design-system';

<Radio
  selected={plan === 'pro'}
  onPress={() => setPlan('pro')}
  label="프로 요금제"
  accessibilityLabel="프로 요금제"
/>;
```

## Props

| prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `selected` | `boolean` | — | 선택 상태 |
| `onPress` | `() => void` | — | 선택 핸들러 |
| `label` | `string` | — | 컨트롤 오른쪽 레이블 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `accessibilityLabel` | `string` | — | 스크린리더 레이블 |

링 20×20 / 도트 10 치수는 `core/tokens/selection.ts`의 `RADIO` 공유.

## 접근성

- Web: `role="radio"` + `aria-checked`
- Native: `accessibilityRole="radio"` + `accessibilityState={{ selected, disabled }}`
