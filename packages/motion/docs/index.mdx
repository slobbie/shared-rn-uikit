`@package/motion`은 웹과 React Native에서 같은 방식으로 사용할 수 있는
애니메이션 컴포넌트와 훅을 제공합니다.

대부분의 화면에서는 `Fade`, `Slide`, `Scale` 중 필요한 효과를 골라 사용하면 됩니다.
`MotionBox`를 따로 추가할 필요는 없습니다.

```tsx
import { Fade, Scale, Slide } from '@package/motion';

<Slide visible={visible} from="bottom">
  <ToastContent />
</Slide>
```

## Components

- [Fade](/docs/motion/components/fade): 요소를 서서히 보여주거나 숨깁니다.
- [Slide](/docs/motion/components/slide): 요소를 원하는 방향으로 움직이며 보여줍니다.
- [Scale](/docs/motion/components/scale): 요소의 크기를 조절하며 보여줍니다.
- [MotionBox](/docs/motion/components/motion-box): 훅과 함께 레이아웃을 직접 구성할 때 사용합니다.

## 크기 설정

`sizing`으로 애니메이션 영역의 크기를 정할 수 있습니다.

| 값 | 설명 |
| --- | --- |
| `inherit` | 부모의 레이아웃 설정을 따릅니다. |
| `intrinsic` | 자식 크기만큼 영역을 차지합니다. |
| `fill` | 부모 너비를 채웁니다. |

## 표시와 숨김

| prop | 기본값 | 설명 |
| --- | --- | --- |
| `visible` | — | 요소를 보여줄지 정합니다. |
| `appear` | `true` | 처음 나타날 때도 애니메이션을 적용합니다. |
| `unmountOnExit` | `true` | 사라지는 애니메이션이 끝나면 요소를 제거합니다. |
| `reducedMotion` | `'system'` | 기기의 동작 줄이기 설정을 따릅니다. |

레이아웃을 직접 지정하거나 여러 효과를 조합해야 한다면
[Hooks](/docs/motion/hooks)을 참고하세요.
